How the Live Editor Works

1

Pick a document

Click My Docs in the top bar. Open the SA31 copy to start from a complete example, or create a new blank document.

2

Edit on the left

Use the collapsible sections in the left panel — Project Header, Scope, Bill of Materials, Drawing Images, Annotation Drawing, and Notes.

3

Watch the right preview

The pages on the right update instantly as you type. Each page is a Singh360-branded slide that mirrors the SA31 PDF.

4

Draw & annotate

In Annotation Drawing, pick a tool (rectangle, ellipse, line, arrow, text, free draw), set stroke/fill/width, and mark up an uploaded background. Everything is saved with the document.

5

Save & export

Edits auto-save (you can also press Ctrl+S). Click Export PDF to print exactly what you see in the preview, including your annotations.

Open via the local server

This editor needs the Singh360 bridge running. It looks like you opened it as a file:// path, so saving, templates, and SA31 data won't work.

Start the server (python server.py) then use this link:

Open http://127.0.0.1:8765/editor
