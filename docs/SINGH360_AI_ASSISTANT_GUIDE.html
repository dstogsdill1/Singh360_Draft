Exact sequence

  1. Start the app.
  2. Select the saved project.
  3. Browse and confirm the workbook.
  4. Verify project/schema/help versions.
  5. Run Workbook Inspector and repair structural problems from a backup.
  6. Choose which page manifest is authoritative.
  7. Review pages and Include/Exclude.
  8. Open the editor.
  9. Export included pages.

Safe synchronization

Every resolution creates matched workbook and project backups first.

Use Workbook Structure updates app page-manifest fields but keeps canvas drawings and assets.

Use App Structure updates 00_INDEX and tab order/colors but keeps worksheet data and app canvas drawings.

Workbook repair

Safe Repair restores control sheets, index schema, Page IDs, tab order/colors, and registers new sheets as excluded. Strict Formatting additionally normalizes indexed table/schedule fonts and borders. Formula errors are reported, never guessed.
