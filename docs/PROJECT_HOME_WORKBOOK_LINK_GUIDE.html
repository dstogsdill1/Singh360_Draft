Singh360 Draft — Project Home and Workbook Linking

The application now opens to Project Home before the page editor.

Start the application

Double-click START_SINGH360_LOCAL.bat. It safely fetches GitHub changes, pulls only when the working tree is clean, rebuilds only when needed, starts port 8766, and opens Project Home.
Run CREATE_SINGH360_DESKTOP_SHORTCUT.bat once to create a normal desktop shortcut.

Link the project workbook

On Project Home, click Browse in Linked Workbook and choose the real G:, Google Drive, OneDrive, network, or local workbook.
Click Confirm Link. The application verifies 00_PROJECT_META and 00_INDEX and shows project/schema/help versions.
For the first link or a conflict, choose Use Workbook → Update App or Use App → Update Workbook. The application does not guess.

Saving

The app saves project.json first. A missing, moved, locked, or conflicting workbook no longer blocks page navigation or local project saves.

MessageMeaning
SavedProject and workbook save completed.
Project saved · workbook sync pendingYour app work is safe. Resolve the workbook link from Project Home.
ConflictBoth versions changed. Choose which version wins.

Project tools

Project Home provides large buttons for Page Editor, Symbol Mapper, Symbol Legend, Component Library, Drawing Set/Export, Reorder/Renumber, Project Package, Backups, and Instructions.
