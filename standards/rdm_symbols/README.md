# Singh360 RDM Symbol Standard

This folder is the committed source of truth for the standardized symbols used
by Singh360 Draft, the published GitHub Pages catalog, and generated PowerPoint
component palettes.

## Standard sizes

- WICP / plan markers: 18 x 18 app units
- Safety signage markers: 22 x 22 app units
- Alarm hardware symbols: 44 x 44 app units
- Refrigeration line symbols: 48-56 x 32 app units

Every plan and signage marker uses the same 64 x 64 SVG canvas, centered
geometry, line weight, and text treatment.

## WICP semantics

- LI: Refrigerant Leak Horn/Strobe
- DA: Door Open Horn/Strobe
- LS: HFC Refrigerant Leak Sensor
- LSB: HFC Leak Sensor in metal enclosure
- LSG: CTI HFC Leak Sensor
- LSC: CO2 Refrigerant Leak Sensor
- ES: Entrapment Switch
- EA: Entrapment Horn/Strobe
- HS: Leak / Horn Silencer Button
- TS: Temperature Sensor
- DS: Defrost Sensor
- DTS: Dual Temperature Switch
