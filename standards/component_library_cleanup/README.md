# Singh360 Component Library Cleanup Standard

This standard is the current canonical component-symbol baseline.

## Main rules

- Connector and line styles belong to the connector tool, not the component library.
- Components may have a primary category and additional categories.
- WICP safety uses LI, DA, LS, ES, EA, and HS.
- LS is the single visible leak-sensor symbol; HFC/CO2/LSB/LSG/LSC remain aliases.
- Mechanical regulator = EPR.
- Electronic regulator = EEPR.
- Evaporator fan and condenser fan are distinct.
- Defrost heater and anti-sweat/trim heater are distinct.
- Only one generic refrigeration rack marker is active.
- Old duplicates are archived, not destroyed.
