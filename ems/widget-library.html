EMS Widget Library

Hillphoenix / Emerson point-to-point I/O symbols — the building blocks for Singh360 controls submittals

These are the reusable symbols that make up the HEB / Hillphoenix I/O wiring schedules (the board-by-board point lists in the survey photos). Each widget below is drawn to match the source sheets and lists the data fields it binds to — the contract the generator fills from the controller dump (dump.xml: 405 controllers, 21,068 params) or the per-controller CSV exports. This page is the visual spec: every symbol here becomes a Visio master and a VSON symbol in the generator.

Network & Controller Boards

CANBUS Connector network
RED / SHIELD / WHITE / BLACK drop to a controller, with cap-off note and end-of-line termination flag.
board_id · terminated(Y/N) · cap_off_note · cable#
Controller Board network
A controller card (PRO661 / PRO650 SUP / PRO752-PHX IP) with its board number. Hosts the I/O sections.
model · board_no · nw/slv address · mac
Title / Revision Block frame
Sheet title block: project ID, store, sheet name, and the revision-record grid.
project_id · store · sheet_title · revisions[]

I/O Point Rows (board sections)

Output Relay Row output
A relay with NC/NO/C dry contacts driving a load (condenser fan, compressor, solenoid, unloader).
relay_no · contact(NC/NO/C) · load · cable#
Probe Input Row analog in
A temperature/sensor input: point number, sensor label, location/type code, and cable number.
point_no · label · loc_type · cable#
Status Input Row digital in
A digital status/alarm input: oil failure, run proof, inverter fault, bypass run proof, etc.
point_no · label · type=DGT · cable#
Universal Signal Row analog
A universal analog I/O point: 4-20mA / 0-10V / 0-5V pressure or VFD speed signal.
point_no · label · signal_type · cable#
Stepper Valve Block valve
An EEPR / stepper valve with its 4 motor terminals (2A/2B/1A/1B) and served circuit.
valve_no · terminals(2A/2B/1A/1B) · served · valve_type
Universal IO Legend frame
The terminal-markings legend that defines each universal point's wiring (reused on every sheet).
static reference · 4 IO types × terminal markings

Refrigeration Schedule (Hillphoenix rack)

Rack / Suction-Group Schedule table
The Hillphoenix circuit schedule: each circuit's ID, load, model, design SST, stub size, and control valve, grouped by suction group with capacity summaries.
rack · suction_group · circuit[id,desc,model,sst,stub,valve] · compressors[] · condenser
