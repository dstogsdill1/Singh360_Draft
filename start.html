1 Start the live tool

1
Open a terminal in the SmartDraw folder
In VS Code, open a terminal and change into the tool's folder.
cd "Singh360_SmartDraw"
2
Install dependencies (first time only)
Installs pandas + Flask. Skip this if you've run it before.
pip install -r requirements.txt
3
Start the bridge
Runs a local server at http://localhost:8765. Leave it running while you work.
python server.py
4
Launch the generator
Click Launch the Generator above (it turns green when the bridge is online), or open http://localhost:8765 in your browser.

Nothing here phones home. The bridge runs entirely on your machine and only serves 127.0.0.1. Stop it anytime with Ctrl+C.

2 What you upload & get back

assets.csv · required
The 11-column Singh360 schedule (one row per asset).
control_matrix.csv · optional
Relay → Contactor → Load control chains.
network.csv · optional
Device → Switch / Port / IP / VLAN.
Blueprint PDF · optional
Floor plan for Azure DI spatial overlay.
You download
.vson (SmartDraw) + .vsdx (Visio), or all as a ZIP.

3 How it works

Browser (this page / the web GUI) │ upload CSVs, click Generate ▼ Flask bridge · localhost:8765 │ runs the exact CLI as a subprocess ▼ main_generator.py │ deterministic · traceable ▼ .vson + .vsdx → download

The browser GUI just drives main_generator.py — the same command-line tool, with no logic duplicated. Every shape traces back to a source file:row.
